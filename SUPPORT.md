# Support

English | [简体中文](SUPPORT.zh-CN.md)

Use [GitHub Issues](https://github.com/cixiangtao/vite-plugin-locator/issues) for reproducible integration bugs, Vite or framework compatibility regressions, documentation errors, and focused feature requests. Include the package, Vite, framework-plugin, Node.js, browser, and editor versions; a minimal reproduction; expected behavior; and actual behavior.

Upstream LocatorJS limitations and editor configuration are supported on a best-effort basis. Report vulnerabilities privately through [Security](SECURITY.md).
